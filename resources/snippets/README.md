# TD Spec Snippets

JSON example snippets rendered inline in the W3C WoT Thing Description specification.

For the complete authoring guide — naming, metadata fields, path notation, groups, validation — see the [Snippet Authoring Guide](../../docs/guidelines/snippet-authoring.md).

The snippet schema is defined in `../schemas/snippet_schema.yaml`. Validate with:

```bash
uv run pytest tests/test_snippet_schema.py -v
```
