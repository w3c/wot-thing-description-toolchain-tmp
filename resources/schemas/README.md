# WoT LinkML Schemas

The LinkML schemas in this directory are the single source of truth for all generated WoT artifacts.

For schema authoring rules, see the [documentation](../../docs/index.md), in particular:

- [LinkML Naming Conventions](../../docs/reference/naming-conventions.md) — class/slot naming, URIs, `slot_usage`, `inlined`, `identifier`, checklists
- [WoT Custom Annotations](../../docs/reference/annotations.md) — `spec_*`, `jsonschema_*` and `jsonld_*` annotations, native LinkML features
- [Postprocessor Conventions](../../docs/internals/postprocessors.md) — writing and maintaining postprocessors
- [LinkML gaps](../../docs/status/linkml-gaps.md) — confirmed generator limitations and workarounds
