# Schema Authoring Rules

Schema authoring rules have been consolidated into the [modeling guidelines](../../docs/guidelines/index.md):

- [LinkML Naming Conventions](../../docs/guidelines/linkml-naming-conventions.md) — class/slot naming, URIs, `slot_usage`, `inlined`, `identifier`, checklists
- [WoT Custom Annotations](../../docs/guidelines/wot-custom-annotations.md) — `spec_*` and `jsonschema_*` annotations, native LinkML features
- [Postprocessor Conventions](../../docs/guidelines/postprocessor-conventions.md) — writing and maintaining postprocessors
- [Known LinkML Gaps](../../docs/known-linkml-gaps.md) — confirmed generator limitations and workarounds

For file responsibility and namespace ownership, see [LinkML Naming Conventions § 4](../../docs/guidelines/linkml-naming-conventions.md#4-prefix-and-namespace-rules).
