# Security Policy

## Supported versions

Only the latest tagged release receives security fixes.

## Reporting a vulnerability

Do not report security issues in public issues or pull requests.

- Use GitHub private vulnerability reporting on this repository
  ("Report a vulnerability" under the Security tab of
  <https://github.com/w3c/wot-thing-description-toolchain-tmp>).
- Alternatively, follow the W3C security contact instructions at
  <https://www.w3.org/Security/>.

## Scope

wot-toolchain is a build-time tool. It processes trusted input: the LinkML
schemas, snippets and project manifest maintained in this repository. Reports
about behavior with untrusted or malicious input are welcome but are assessed
with that scope in mind.
